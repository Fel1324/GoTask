# GoTask

O **GoTask** é uma aplicação web de gerenciamento de tarefas feita com Angular. Organize atividades em um quadro visual, acompanhe o andamento com arrastar e soltar e mantenha seus dados salvos no navegador.

<br>

## ✨ Recursos

- Criar tarefas com nome e descrição.
- Visualizar tarefas nas colunas **A fazer**, **Fazendo** e **Concluído**.
- Mover e reordenar cartões com arrastar e soltar.
- Editar ou excluir tarefas.
- Adicionar e apagar comentários em cada tarefa.
- Persistir tarefas e comentários no `localStorage` do navegador.
- Validar nome e descrição: ambos precisam ter pelo menos 10 caracteres.

<br>

## 🧰 Tecnologias

- [Angular](https://angular.dev/) 19
- TypeScript 5
- RxJS 7
- Angular CDK — dialogs e drag and drop
- Tailwind CSS 4

<br>

## 🚀 Começar

### Pré-requisitos

- Node.js e npm instalados
- Um navegador moderno

### Instalação e execução

Clone o repositório e entre na pasta do projeto. Depois, instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm ci
npm start

Abra o endereço exibido no terminal (por padrão, `http://localhost:4200/`).
```
